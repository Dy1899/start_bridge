# 星桥远控 0.1.3 · 两台电脑局域网测试

适用于 Windows 10/11 x64，两台电脑连同一个路由器；有线连接和 Wi-Fi 可以混用。

1. 两台电脑都解压整个软件包，保留 StarBridge.exe、resources 和旁边的 DLL。
2. 先关闭旧版本的软件窗口和“本机服务”窗口，避免占用 8787 端口。
3. 只在其中一台电脑 A 双击“启动局域网服务.cmd”，保持这个窗口打开。电脑 B 不必启动服务。
4. 服务窗口会显示内网地址，例如 ws://192.168.20.57:8787。地址以该窗口当前显示为准；有多个地址时，选连接路由器的 Wi-Fi 或以太网地址，跳过 VMware、WSL 等虚拟网卡。
5. 两台电脑打开 StarBridge.exe，进入“连接设置”，填写同一个上述地址并保存；不要勾选“强制使用 TURN 中继”。确认左下角都是 v0.1.3，右上角显示“连接服务已就绪”。
6. 在被控端选择共享屏幕，第一次可勾选“仅允许观看”。把它的识别码和临时访问码填到另一台电脑，发起连接。
7. 被控端在本机确认，再点击“开始共享选定屏幕”。画面出现后，若要测试键鼠控制，重新连接并取消“仅允许观看”，然后点击远程画面操作。
8. 结束时点击“结束连接”，或在被控端按 Ctrl+Alt+F12。

如果弹出 Windows 防火墙提示，按你当前的网络环境允许本程序在专用网络访问。无需关闭防火墙。

## 连不上时

- 服务窗口显示“8787 端口正在使用”：关闭旧的本机服务或重复打开的局域网服务，再运行一次。
- 电脑 B 连接服务失败：在 B 的浏览器中打开 http://电脑A的内网IP:8787/healthz，例如 http://192.168.20.57:8787/healthz。看到 ok:true 说明能访问连接服务。
- 若上述网页也打不开：检查两台电脑是否属于同一路由器下的网络、是否连到了访客 Wi-Fi，以及 Windows 专用网络是否允许了本程序。
- 服务已就绪但没有画面：先关闭强制中继，重新连接并确认共享；把被控端的完整红色提示发来。日志在软件目录 data/logs。

## 地址和测试范围

- ws://127.0.0.1:8787 只代表当前电脑。两台电脑测试请填写电脑 A 的内网 IP。
- 当前局域网测试使用 ws:// 地址，连接协商未经 HTTPS 加密，请只在信任的内网中使用。画面和控制通过 WebRTC 传输。异地测试请部署 HTTPS 与 TURN 服务并使用 wss:// 地址。
- 0.1.3 已包含 0.1.2 的屏幕权限修复，新增局域网连接地址与服务启动入口。
- 自动检查 19 项通过；仍需这次由你在两台真实电脑上验证画面和键鼠。
