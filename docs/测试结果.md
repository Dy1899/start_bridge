# 星桥远控 0.1.0 验证记录

日期：2026-10-20。

## 已通过

- Node.js 自动测试 7 项全部通过：本地授权与会话绑定、只读/过期授权、公开明文信令拒绝、输入动作白名单、带黑边画面的坐标映射、原生 x64 输入组件无操作验证、信令请求/断线清理、TURN 凭据计算。部分项目在同一个测试用例中覆盖多个检查点。
- Windows 输入组件已用系统 C# 编译器编译，x64 INPUT 结构大小实测为 40 字节；验证模式解析有效和无效命令时未操作真实桌面。
- 打包后的 StarBridge.exe 以自带 Node 运行模式启动连接服务，HTTP healthz 与 WebSocket 设备注册均通过；运行该服务不需另外安装 Node.js。
- 在内置浏览器中，以测试桥接层加载正式界面资源，检查了布局及真实本机服务注册。该桥接层只用于测试，不具备桌面采集或原生输入权限，也不包含在软件包中。
- 浏览器内 WebRTC 测试通过：两个端点经实际信令服务建立连接，收到了合成画面的视频帧，有序 DataChannel 控制数据往返成功。测试未采集真实桌面、未注入原生输入。

## 尚未完成的实机验证

当前 Codex 隔离环境内，Electron 的 Windows 安装目录读取权限自检失败，桌面进程未能启动。为程序依赖目录补充只读权限后仍然失败；未关闭沙盒、未降低验证检查。因此尚未在此环境验证真实 Electron 窗口、本机授权弹窗、真实屏幕采集到远端的完整链路，以及真实鼠标键盘输入。

需要在普通 Windows 用户会话中打开整个免安装文件夹进行上述验证。不能依据浏览器合成画面测试推断这些实机步骤已通过。

当前没有公网服务器；Docker 部署模板未在云服务器执行，也未验证公网直连、强制 TURN 中继、系统声音、混合 DPI 多屏和中文输入法。

这是可构建、已打包的远程协助原型，尚未达到成熟远控软件的实机验证程度。
