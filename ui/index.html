连接服务

两台电脑填写相同的服务地址。

同机测试：ws://127.0.0.1:8787。局域网：填写服务窗口显示的内网地址。内网测试地址仅在你信任的网络中使用；异地连接使用 wss:// 域名。

开始一次远程协助

  1. 两台电脑打开星桥远控，在“连接设置”中填写同一个服务地址。
  2. 被控端选择共享屏幕，将识别码和临时访问码告诉控制端。
  3. 控制端输入信息并发起连接，被控端在弹出的本机窗口中确认。
  4. 被控端点击“开始共享选定屏幕”；控制端点击远程画面即可操作。
  5. 结束时点击“结束连接”。被控端也可按 Ctrl+Alt+F12 随时断开。

首次本机测试

先启动随附的“启动本机服务.cmd”，再打开两个软件窗口。测试时建议勾选“仅允许观看”，避免同屏操作互相影响。

同一 Wi-Fi／路由器下测试

只在一台电脑运行“启动局域网服务.cmd”，保持服务窗口打开。两台电脑都在“连接设置”填写该窗口显示的同一个内网地址，例如 ws://192.168.20.57:8787。另一台电脑不必启动服务。若弹出防火墙提示，请按你的网络环境允许专用网络访问。

跨互联网使用

部署包包含连接服务、HTTPS 入口和 TURN 中继配置。完成云服务器部署后，双方填写同一个 wss:// 服务地址。当前版本未代你部署公网服务。

画质与流畅度

看视频或日常操作先用“高清流畅”（目标 1080p / 60 帧，码率上限 16 Mbps）；卡顿时切到“流畅优先”（目标 720p / 60 帧，上限 8 Mbps）；阅读细字可用“文字清晰”（目标 1440p / 30 帧，上限 18 Mbps）。这些是目标上限，实际效果取决于屏幕、编码能力和网络。两端均为 v0.1.4 时，控制端可直接切换；旧版被控端需先升级。点击“全屏”可扩大画面。状态栏显示实际接收分辨率、帧率和网络往返时间，往返时间不代表操作到画面的总延迟。

比较编码与定位卡顿

被控端可在共享前选择自动、H.264 优先或 VP8 兼容模式。切换编码需要结束当前连接再共享；不可用时保留系统默认格式。会话中的“性能详情与报告”会显示实际编码格式、两端分项耗时和瓶颈提示。两端都升级到 v0.1.5 后可查看完整统计，旧版对端仍可连接。点击保存报告，将最近 60 次采样存入程序目录 data/reports；断开后也可保存最近一轮报告。

当前版本范围

支持手动确认的 Windows 桌面协助。暂不支持 UAC/登录安全桌面、文件传输、无人值守、PS5 Remote Play。中文输入法、不同键盘布局及混合 DPI 多屏需要实机验证。
